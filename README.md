# Astara Growth Radar v5

App web móvil/PWA para GitHub Pages.

## Cómo subir
1. Sube todos estos archivos a la raíz del repo:
   - index.html
   - manifest.json
   - sw.js
   - assets/
2. En GitHub: Settings > Pages > Deploy from branch > main > /root.
3. Abre el link de GitHub Pages, no el archivo index.html dentro de GitHub.

## Para guardar en inicio
- iPhone: Safari > Compartir > Agregar a pantalla de inicio.
- Android: Chrome > menú > Instalar app / Agregar a pantalla principal.

Incluye noticias automáticas vía Google News RSS. Si el navegador bloquea la consulta, muestra respaldo local.
