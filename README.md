# Astara Growth Radar v4

## Cómo subirlo a GitHub Pages

1. Descomprime el ZIP.
2. Sube el contenido de la carpeta a la raíz del repositorio. Deben verse estos archivos directamente:

```
index.html
manifest.json
sw.js
assets/
README.md
```

3. En GitHub: Settings > Pages > Deploy from a branch > main > /root.
4. Abre el link de GitHub Pages, no el archivo index.html dentro de GitHub.

## Qué cambia en esta versión

- Noticias automáticas vía Google News RSS usando un proxy público.
- Fuentes filtradas hacia medios serios y sectoriales.
- Tipo de cambio USD/PEN actualizado en vivo.
- Logo/wordmark de Astara visible en cabecera.
- Manifest + íconos para guardar en pantalla de inicio como “Astara Radar”.
- Fuentes y metodología escondidas en la pestaña Acciones.

## Nota

Los KPIs oficiales se actualizan cuando AAP/SUNARP publica reportes. Los rankings exactos por marca pueden conectarse luego si se cuenta con una fuente abierta, CSV propio o reporte de pago.
